# 中原大學大一通識排課模擬器

直接以瀏覽器開啟 `index.html` 即可使用，不需要安裝任何程式或上傳資料到伺服器。

## 已依附件確認的格式

首列欄位為：`課程名稱`、`授課教師`、`時間1`、`教室1`、`時間2`、`教室2`。

時間格式採 `星期數字-節次`，例如 `1-34` 表示週一第 3、4 節；`4-7` 表示週四第 7 節。完整節次支援 `A、1–4、B、5–8、C–F`，因此 `3-CDE` 也可正確排入課表。

## 使用方式

1. 首次開啟已載入本次附件的 9 門必修；要換課表可選擇「選擇 Excel 檔」。
2. 推薦區已含中原官方查詢系統的 115-1 實際開課資料；點選「加入課表」前，網站會先檢查衝堂。時間未被官方課表驗證的課程不能加入，以免排出錯誤結果。
3. 用「手動新增課程」將選課系統中查到的通識加入排課；輸入星期、節次及學分。
4. 點擊課表的課程，可解除必修鎖定或刪除非鎖定課程。

提醒：必修附件沒有學分欄位，因此網站不會猜測必修學分；學分統計會將未提供項目獨立標示。
